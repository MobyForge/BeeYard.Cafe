# BeeYard.Cafe 🐝

A modern, responsive static website designed for **BeeYard.Cafe**, a vibrant café in Bengaluru.

## About

BeeYard.Cafe serves flavorful pasta, cheesy pizzas, juicy burgers, refreshing beverages, and more. The website provides customers with an easy way to explore the café, view the menu, browse photos, and find contact/location information.

## Features

- 🏠 **Home & About** — Café introduction and brand story
- 🍕 **Menu** — Dedicated menu page with food and beverage listings
- 📸 **Mini Gallery** — Café photos and visual highlights
- 📍 **Contact** — Location and contact information
- 💬 **WhatsApp** — Direct WhatsApp contact button
- 🐝 **Bee-Themed Design** — Honeycomb, bee and honey-inspired visual elements
- ✨ **Light Animations** — Subtle hover and scroll animations
- 📱 **Responsive Design** — Optimized for desktop, tablet and mobile

## Tech Stack

- **HTML5**
- **CSS3**

## Design

The website follows a **Bee & Beehive** theme inspired by:

- Honey and golden tones
- Honeycomb patterns
- Bee-inspired details
- Clean café aesthetics
- Smooth, subtle animations

The goal is to create a distinctive café identity rather than a generic restaurant template.

## Deployment

The website is deployed using **Vercel** from the GitHub repository.

Since the project files are inside the `beeyard-web` directory, configure the Vercel **Root Directory** as:

```text
beeyard-web
```

No build command is required because this is a static HTML/CSS/JavaScript project.

## Local Development

Clone the repository:

```bash
git clone <repository-url>
```

Open the project:

```bash
cd beeyard-web
```

Then open `index.html` in a browser, or use a local development server such as VS Code Live Server.

## Customization

To update the website:

- Replace images inside `assets/`
- Update menu items in `menu.html`
- Update contact details in `contact.html`
- Update WhatsApp number/link
- Modify styling in the CSS files
- Update JavaScript interactions as required
